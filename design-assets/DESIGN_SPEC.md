## 1. 品牌定义

### 1.1 产品命名

**产品名：姿势企鹅（PosturePenguin）**

命名理由：

- **企鹅是少数"站得笔直"的动物**（寓意：即便忙碌也要保持好姿态）
- 企鹅形象：萌、圆润、亲和力强，女性用户接受度高
- IP 化空间大：可延伸表情包、周边、联名
- 国内南极/生态好感联想，无负面文化含义
- 竞品空白：市面上暂无企鹅主题的姿势类产品

### 1.2 吉祥物形象

**形象名称：小企鹅 "Pongo"**

- 性别：无（通用中性）
- 性格：温柔、关心主人、偶尔有点着急希望主人健康
- 配色：白色脸部 + 黑色身体 + 橙色嘴巴和脚（经典企鹅配色）
- 表情体系：idle（歪头眨眼）/ 提醒（挥手）/ 成就（戴勋章）/ 伤心（低头）
- 设计风格：简约圆润插画风格（参考 Line Friends + Tuzki 路线）

## 4. 图标风格规范

### 4.1 图标设计原则

- **风格**：圆润线性图标（圆角半径 2-3px）
- **线宽**：统一 1.5px stroke
- **尺寸基准**：24x24px（主图标）、20x20px（辅助图标）
- **动物元素**：图标可融入小型企鹅装饰元素（围巾、帽子等）
- **颜色**：使用品牌色 `#5B7A8A` 作为图标默认色

### 4.2 核心图标列表

| 功能     | 图标描述             |
| -------- | -------------------- |
| 主页     | 憨憨站立的企鹅       |
| 拍照检测 | 摄像头 + 企鹅眼睛    |
| 设置     | 齿轮围着小型企鹅     |
| 数据统计 | 企鹅戴着博士帽看图表 |
| 提醒弹窗 | 企鹅挥手的小动画图标 |
| 拉伸建议 | 企鹅在做拉伸动作     |

## 6. 核心界面设计

### 6.1 主页（Home）

- 顶部：品牌 Logo + 企鹅吉祥物动画区
- 今日姿势评分（大字号圆形进度环）
- 今日检测次数统计
- 快速操作入口（拍照检测/设置/统计）
- 姿势小贴士卡片（每日更新）

### 6.2 拍照检测页（Detection）

- 摄像头预览区域（带企鹅边框装饰）
- 实时姿势评分（检测中动画）
- 企鹅吉祥物动画区（Pongo 在观察你）
- 开始/停止检测按钮

### 6.3 设置页（Settings）

- 检测间隔设置（滑块 + 预设按钮）
- 提醒音量控制
- 隐私设置说明（摄像头本地处理强调）
- 每日提醒时间段设置
- 关于我们 / 隐私协议

### 6.4 统计页（Statistics）

- 姿势评分趋势折线图（周视图/月视图切换）
- 各问题类型分布饼图
- 进步/退步对比卡片
- 周月报告下载入口（付费标识）

### 6.5 姿势提醒弹窗（Alert Modal）

- 企鹅挥手动画区
- 姿势问题描述（温柔语气）
- 拉伸/改善建议（图文卡片）
- "我知道了"按钮
- 5秒自动消失进度条

### 6.6 成就卡片（Achievement Card）

- 今日姿势达人徽章
- 评分 + 鼓励语
- 分享到小红书入口
- 品牌 Logo + 企鹅装饰
