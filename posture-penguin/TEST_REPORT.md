## 🐛 Bug 发现与修复

### [P1] 图标尺寸错误 — ✅ 已修复

**问题描述：** 所有 PNG 图标文件均为 16×16 像素，Chrome Web Store 要求 128×128。

**影响：** 无法通过 Chrome Web Store 审核。

**修复方式：** 使用 Python PIL 重新生成正确尺寸图标（16, 32, 48, 128 px）。

```bash
# 修复前
dist/icons/icon128.png: PNG 16x16  ❌

# 修复后
dist/icons/icon128.png: PNG 128x128 ✅
dist/icons/icon48.png:  PNG 48x48   ✅
dist/icons/icon32.png:  PNG 32x32   ✅
dist/icons/icon16.png:  PNG 16x16   ✅
```
