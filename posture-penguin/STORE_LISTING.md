## 🖼️ 截图要求 (Screenshots)

Chrome Web Store 要求：

- **最小尺寸：** 1280×720 像素
- **格式：** PNG 或 JPEG（非动画）
- **数量：** 至少 1 张，建议 4-8 张
- **比例：** 16:9（横版）或 9:16（竖版）

### 建议截图内容（需手动从运行插件中截取）：

| #   | 截图内容                            | 尺寸     |
| --- | ----------------------------------- | -------- |
| 1   | 主页面（今日姿势评分圆环+检测按钮） | 1280×720 |
| 2   | 手动检测页面（摄像头+姿势骨架）     | 1280×720 |
| 3   | 数据统计页面（折线图+周视图）       | 1280×720 |
| 4   | 设置页面（检测间隔+提醒时段）       | 1280×720 |

截取方法：

1. 在 Chrome 中加载插件（chrome://extensions/ → 开发者模式 → 加载已解压）
2. 点击插件图标打开 popup
3. 使用 Mac 截图（Cmd+Shift+4）或 Chrome 开发者工具截图
4. 上传到 Chrome Web Store Developer Dashboard
