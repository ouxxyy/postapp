# 姿势企鹅 (PosturePenguin) 隐私政策

**最后更新日期：** 2026年4月4日

## 我们收集什么

姿势企鹅是一款注重隐私保护的 Chrome 浏览器插件。我们**不会**收集、存储或上传任何个人数据。

### 具体说明：

- **摄像头图像**：您的摄像头图像仅在本地浏览器中处理，**不会**上传至任何服务器
- **姿势检测数据**：所有姿势检测结果（如坐姿评分、问题类型）仅存储在您浏览器的本地存储中（chrome.storage.local）
- **使用统计**：我们不追踪或收集任何使用行为数据
- **第三方服务**：我们不使用任何第三方分析或追踪服务

## 数据存储

- 所有用户数据（设置、姿势检测记录）存储在 `chrome.storage.local` 中
- 数据仅保存在用户本地设备上
- 用户可随时通过清除浏览器数据手动删除所有存储数据
- 历史数据在 90 天后自动清理

## 权限使用说明

| 权限             | 用途                                   |
| ---------------- | -------------------------------------- |
| `storage`        | 保存用户设置和检测记录                 |
| `alarms`         | 定时姿势检测提醒                       |
| `notifications`  | 姿势问题提醒通知                       |
| `tabs`           | 管理插件图标徽章                       |
| `camera`（可选） | 仅用于实时姿势检测，所有处理在本地完成 |
