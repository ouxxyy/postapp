## 一、久坐的危害，比你想象的严重

### 1.1 颈椎：每低头15°，颈椎多承重12公斤

根据美国脊椎神经外科协会数据：

| 低头角度   | 颈椎承重 |
| ---------- | -------- |
| 0°（直视） | 5公斤    |
| 15°        | 12公斤   |
| 30°        | 18公斤   |
| 45°        | 22公斤   |
| 60°        | 27公斤   |

**相当于你的脖子上，每天压着一袋大米在工作。**

### 1.2 驼背：不只是丑，更是健康杀手

头前倾（电脑颈）不仅导致：

- 颈椎退行性病变（年轻化趋势明显）
- 偏头痛和眩晕
- 呼吸变浅（心脏负担增加）
- 体态变形（显胖、显老）

**很多20多岁的年轻人，颈椎已经相当于40岁的状态。**

### 1.3 肌肉记忆：越久坐，姿势越差

肌肉是有记忆的。
长期错误姿势 → 相关肌肉紧张/无力 → 错误姿势被"固化"
→ 矫正难度呈指数增长

**越早干预，效果越好。**

## 四、3步自检：你现在的姿势达标吗？

**方法一：墙壁测试**
背靠墙站立，后脑勺/肩胛骨/臀部/脚跟贴墙
感受：脖子是否不自觉前倾？下巴是否有明显肉堆积？

**方法二：手机侧拍**
让同事/手机定时拍摄你侧面坐姿照片
观察：耳垂 vs 肩峰是否在一条垂直线上
