## 一、产品定位回顾

| 维度       | 内容                                                    |
| ---------- | ------------------------------------------------------- |
| 产品名     | 姿势企鹅 (PosturePenguin)                               |
| Slogan     | "一个长在你电脑里的小企鹅，随时盯着你的姿势"            |
| 核心功能   | 定时 Webcam 抓拍 + 本地 AI 姿势检测 + 温柔弹窗提醒      |
| 核心差异化 | 100% 本地隐私处理 · 企鹅 IP 萌系设计 · 非侵入式温柔提醒 |
| 目标用户   | 22-40 岁久坐白领（尤其女性），小红书/Keep 重度用户      |
| 变现模式   | ¥18/月 or ¥128/年（周月报+详细图表为核心付费点）        |

## 二、渠道内容定位 & 发布节奏

### 2.1 小红书（主战场 · 种草 + 曝光）

| 内容类型 | 定位                                          | 发布节奏    |
| -------- | --------------------------------------------- | ----------- |
| 种草笔记 | 软性产品介绍，突出"可爱企鹅陪我上班"          | 第1周 · 2篇 |
| 使用教程 | 3步上手截图教程，降低使用门槛                 | 第1周 · 1篇 |
| 对比测评 | vs 某品牌/vs 旧方法，突出隐私保护优势         | 第2周 · 1篇 |
| 场景故事 | "我的一天工作+姿势企鹅陪我" 日记型            | 第3周 · 1篇 |
| 话题标签 | #坐姿监测 #姿势矫正 #企鹅 #打工人家 #健康办公 |

**内容风格**: 温暖、治愈、图文并茂；配企鹅吉祥物插画；结尾有 CTA（评论区互动/主页链接）

### 2.2 微信公众号（深度内容 · 信任建立）

| 内容类型       | 定位                              | 推送节奏 |
| -------------- | --------------------------------- | -------- |
| 产品功能介绍文 | 详细介绍核心功能+使用场景         | 第1周    |
| 坐姿科普文     | 驼背危害+医学建议（丁香医生风格） | 第2周    |
| 姿势改善指南   | "坐着也能瘦"健康知识型            | 第3周    |

**内容风格**: 专业+温度并重；文末有产品下载/官网链接

### 2.3 视频号/抖音（短视频 · 场景演示）

| 内容类型     | 定位                            | 发布节奏    |
| ------------ | ------------------------------- | ----------- |
| 功能演示视频 | 录屏+企鹅动画，展示完整提醒流程 | 第1周 · 1条 |

**视频风格**: 15-60秒竖版；前3秒有钩子；字幕+企鹅贴纸

## 三、首批内容主题规划（各渠道≥2条）

### 小红书（4条）

1. **「打工人的第一天，从姿势企鹅开始」** — 开箱/种草软文
2. **「3步设置，姿势企鹅24小时守护我的腰」** — 使用教程截图
3. **「vs某品牌：为什么我选择这个不联网的姿势检测？」** — 对比测评
4. **「连续使用一周，我的颈椎发生了什么变化」** — 体验分享

1. **「久坐，正在悄悄毁掉你的颈椎」** — 坐姿科普文（软植入产品）
2. **「姿势企鹅正式上线！附完整使用指南」** — 产品发布文

1. **「当姿势企鹅检测到你驼背时…🐧」** — 功能演示（15秒）
